# 智慧乡村地图与便民服务原型

一套可本地运行、可现场演示的原型系统，包含**网页端地图展示平台**与**小程序端便民助手**。

- 网页端：`http://localhost:5178/web/` — 综合态势、村户一张图、政策智能问答、基础数据管理
- 小程序端：`http://localhost:5178/app/` — 普通版 / 长辈版首页、服务分类、通知、网点、语音咨询、收藏、反馈
- 入口页：`http://localhost:5178/`

![村户一张图](docs/screenshots/web-02-households.png)

## 快速开始

```bash
cd F:\便民服务
npm install
npm start
```

浏览器打开 <http://localhost:5178/>。

自动化测试与截图：

```bash
npm test          # 接口 / 权限 / 脱敏用例 45 项，输出 docs/测试记录.md
npm run test:ui   # 页面交互用例 24 项（需先 npm start），输出 docs/UI测试记录.md
npm run shots     # 自动截图到 docs/screenshots（需先 npm start）
```

## 特点

1. **真实地图定位**：428 户点位由卫星影像中的房屋位置识别而来（WGS84 经纬度），不是示意图；支持卫星影像与矢量底图切换，矢量底图自动做 WGS84→GCJ02 纠偏。
2. **权限与脱敏**：列表与详情默认脱敏（`138****2468`、`张某`）；完整台账仅管理员可见，并写入审计日志。
3. **结构化政策答复**：答案统一按“适用对象 / 所需材料 / 办理流程 / 办理地点 / 政策依据”组织，无法确认的信息标注“待确认”并支持转人工。
4. **长辈版**：大字号、大按钮、一键语音，与普通版共用同一套数据与接口。
5. **可演示、可追溯**：通知、网点、事件、反馈均可在管理端维护；测试脚本自动还原数据。

## 数据与合规说明

- 所有姓名、电话、户号、身份证号、统计数据均为虚构或脱敏示例，不含真实个人信息。
- 农户坐标由公开卫星影像中的房屋位置换算后叠加随机偏移生成，仅用于演示“点位落图”效果。
- 地图底图为公开在线地图服务（Esri World Imagery / 高德矢量），仅用于原型演示；正式环境应替换为政务地图服务。
- 本项目为演示原型，未做生产级鉴权、加密与审计合规处理，不建议直接上线。
