# 智慧乡村地图与便民服务原型

一套可本地运行、可现场演示的原型系统，包含**网页端地图展示平台**与**小程序端便民助手**。

- 网页端：`http://localhost:5178/web/` — 综合态势、村户一张图、政策智能问答、基础数据管理、数据录入（模板 / 批量导入）、系统接入（地图服务 / 视频监控）
- 小程序端：`http://localhost:5178/app/` — 普通版 / 长辈版首页、服务分类、通知、网点、语音咨询、收藏、反馈
- 入口页：`http://localhost:5178/`

![村户一张图](docs/screenshots/web-02-households.png)

## 快速开始

```bash
cd F:\便民服务
npm install
npm start
```

浏览器打开 <http://localhost:5178/>。

自动化测试与截图：

```bash
npm test          # 接口 / 权限 / 脱敏 / 导入用例 90 项，输出 docs/测试记录.md
npm run test:ui   # 页面交互用例 56 项（需先 npm start），输出 docs/UI测试记录.md
npm run shots     # 自动截图到 docs/screenshots（需先 npm start）
```

可选环境变量：`PORT`（默认 5178）、`TIANDITU_KEY`（天地图密钥）、`MAP_PROVIDER`（默认底图）。

## 特点

1. **真实地图定位**：428 户点位由卫星影像中的房屋位置识别而来（WGS84 经纬度），不是示意图；底图通过 `data/map-providers.json` 可插拔配置（Esri 影像 / 高德矢量 / 天地图 / 自建瓦片），矢量底图自动做 WGS84→GCJ02 纠偏。
2. **权限与脱敏**：列表与详情默认脱敏（`138****2468`、`张某`）；完整台账仅管理员可见，并写入审计日志；写操作仅管理员可执行。
3. **模板化数据录入**：5 类数据（农户 / 网点 / 摄像头 / 通知 / 事件）统一由 `server/schemas.js` 描述，自动生成 CSV 模板、字段说明、单条表单与逐行校验；支持 Excel 复制粘贴批量导入，先校验后入库，按唯一键去重。
4. **视频监控接口预留**：GB/T 28181、RTSP、HLS、RTMP、WebRTC 五种接入形态统一抽象，含设备清单、在线率统计、实时抓图、云台控制；当前为占位实现，换真设备只需改 `data/cameras.json` 与前端播放器。
5. **结构化政策答复**：答案统一按“适用对象 / 所需材料 / 办理流程 / 办理地点 / 政策依据”组织，无法确认的信息标注“待确认”并支持转人工。
6. **长辈版**：大字号、大按钮、一键语音，与普通版共用同一套数据与接口。
7. **可演示、可追溯**：通知、网点、事件、反馈均可在管理端维护；测试脚本自动还原数据。

## 数据维护口径

| 数据 | 删除方式 | 说明 |
| --- | --- | --- |
| 服务网点 | 物理删除 | `DELETE /api/points/:id`，页面有按钮 |
| 通知公告 | 物理删除 | `DELETE /api/notices/:id`，页面有按钮 |
| 摄像头设备 | 物理删除 | `DELETE /api/cameras/device/:id`，「系统接入」页可新增 / 编辑 / 删除 |
| 农户台账 | 标记退出 | 状态改为 `已搬迁 / 已拆除`，记录保留、不计入常住户（stats 返回 `resident` / `retired`） |
| 事件记录 | 标记作废 | 状态改为 `已作废`，记录保留、不计入待处置与告警，可随时恢复 |

台账类数据不提供物理删除，避免历史事件、走访记录与统计口径出现孤儿数据。

## 数据与合规说明

- 所有姓名、电话、户号、身份证号、统计数据均为虚构或脱敏示例，不含真实个人信息。
- 农户坐标由公开卫星影像中的房屋位置换算后叠加随机偏移生成，仅用于演示“点位落图”效果。
- 地图底图为公开在线地图服务（Esri World Imagery / 高德矢量），仅用于原型演示；正式环境应替换为政务地图服务。
- 本项目为演示原型，未做生产级鉴权、加密与审计合规处理，不建议直接上线。
