# 智慧乡村地图与便民服务原型 · 使用说明

> 版本：v1.1（演示原型）　更新时间：2026-10-20
> 本系统所有姓名、电话、户号、身份证号、统计数据均为**脱敏或虚构的演示数据**，不接入任何真实业务系统，不涉及真实个人信息。
>
> v1.1 新增：数据录入（模板下载 + 粘贴批量导入 + 逐行校验）、系统接入（底图服务可插拔配置 + 视频监控能力接口），以及网页端科技感视觉增强。

## 一、原型包含什么

| 端 | 访问地址 | 主要能力 |
| --- | --- | --- |
| 网页端（治理平台） | `http://localhost:5178/web/` | 综合态势、村户一张图（真实地图 + 428 户点位）、户详情卡与权限控制、政策智能问答、基础数据管理、**数据录入（模板 / 批量导入）**、**系统接入（地图服务 / 视频监控）** |
| 小程序端（村民服务） | `http://localhost:5178/app/` | 普通版/长辈版首页、服务分类、通知公告、服务网点地图、文字/语音咨询、结构化政策答复、收藏、意见反馈 |
| 原型入口页 | `http://localhost:5178/` | 两端入口与说明 |

关于地图：**农户点位不是示意图，而是基于卫星影像中真实存在的房屋位置生成的经纬度**，因此可以落在实际地图的房屋上；支持多套底图（Esri 影像、高德矢量、天地图、自建瓦片），矢量底图已做 WGS84→GCJ02 坐标纠偏，切换后点位仍然对得上。底图服务通过 `data/map-providers.json` 配置，可在网页端「系统接入」页面直接查看与切换。

关于视频监控：**摄像头能力已抽象为统一接口**（GB/T 28181、RTSP、HLS、RTMP、WebRTC 五种接入形态），当前演示使用服务端生成的占位抓图，真实设备只需替换 `data/cameras.json` 中的地址与协议即可对接。

## 二、启动方式

### 1. 环境要求

- Node.js ≥ 18（推荐 22）
- 可访问外网（地图瓦片来自公开在线地图服务：Esri 影像 / 高德矢量）

### 2. 安装与启动

```bash
cd F:\便民服务
npm install          # 首次运行需要，安装 express / leaflet
npm start            # 启动服务，默认端口 5178
```

启动后终端会打印三个地址，浏览器打开 `http://localhost:5178/` 即可看到入口页。

端口被占用时可临时改端口：

```bash
# Windows PowerShell
$env:PORT=8080; npm start
```

可选环境变量：

| 变量 | 说明 |
| --- | --- |
| `PORT` | 服务端口，默认 5178 |
| `TIANDITU_KEY` | 天地图密钥，配置后「系统接入」页的天地图底图自动启用 |
| `MAP_PROVIDER` | 指定默认底图（缺省按 `map-providers.json` 的 `defaultGroup` 取） |

### 3. 运行自动化测试

```bash
npm test          # 接口与权限用例（75 项），生成 docs/测试记录.md
npm run test:ui   # 页面级交互用例（44 项，需先 npm start），生成 docs/UI测试记录.md
npm run shots     # 自动截图到 docs/screenshots（需先 npm start）
npm run check:templates  # 自检 5 类 CSV 模板的示例行能通过导入校验（需先 npm start）
```

接口测试脚本会自行拉起独立端口的服务，不影响正在运行的演示服务；页面测试复用本机 Edge 浏览器，无需额外下载 Chromium。

### 4. 重新生成演示数据（可选）

```bash
npm run gen:data        # 重新生成 data/*.json（需要 Python 3 + Pillow/NumPy）
npm run gen:footprints  # 重新从卫星影像识别房屋点位（联网下载瓦片）
```

> 数据生成脚本会从公开卫星影像中识别房屋轮廓并换算为经纬度，输出到 `data/` 目录。

## 四、网页端操作指引

### 1. 综合态势

- 顶部四张指标卡：总户数、常住人口、摄像头在线、待处置事件。
- 中间「村情概览」：卫星影像底图 + 5 个村域边界 + 服务网点 / 摄像头 / 事件点位；右上角可放大、缩小、全屏。
- 右侧「实时预警」：按时间倒序列出待处置与已处置事件。
- 底部三张趋势图：人口趋势（折线）、户数趋势（双轴柱状）、事件趋势（分组柱状）。

### 2. 村户一张图（核心页面）

| 操作 | 说明 |
| --- | --- |
| 点击地图上的蓝点 | 右侧打开「农户详细信息」抽屉 |
| 左侧「图层控制」 | 分别开关农户 / 网点 / 摄像头 / 事件 / 村域边界 |
| 左侧「快速筛选」 | 全部农户、待核查、重点关怀、闲置房屋 |
| 地图上方搜索框 | 输入户号（如 `A-023`）、户主姓氏（如 `张`）、门牌关键字，回车定位 |
| 地图上方「底图」下拉 | 在配置的底图服务间切换（影像 / 矢量 / 天地图…），矢量图已做坐标纠偏 |
| 点击地图上的摄像头 | 左下弹出「视频监控面板」：实时抓图、AI 标签、云台控制、抓拍/录像 |
| 抽屉内「查看完整台账」 | 管理员可看；网格员会提示无权限并可申请 |

权限演示：右上角「管理员 / 网格员」随时切换。切换为网格员后再打开完整台账，会看到拒绝提示；切回管理员即可查看，同时后端会写入一条审计日志。

### 3. 政策智能问答

- 左侧为对话历史与话题分类，点击话题会把示例问题填进输入框。
- 输入问题（或点麦克风按钮模拟语音）后，答案按「适用对象 / 所需材料 / 办理流程 / 办理地点 / 政策依据」结构化展示。
- 办理地点如无法确认，会显示「待确认」标签；底部可「有帮助 / 没帮助 / 转人工」。
- 右侧同步展示相关政策文件，可点击「查看原文」（演示占位）。

可试问：
```
农机购置补贴怎么申请？
医保报销比例是多少？
宅基地申请需要什么条件？
高龄津贴怎么领？
```

### 4. 基础数据管理

四个页签：农户台账、服务网点、通知公告、事件记录。

- 网点：支持新增、编辑、删除。
- 通知：支持新增、删除。
- 事件：支持在「待处置 / 已处置」之间切换。
- 农户：仅允许维护房屋状态、家庭人数、关怀标签（防止误改敏感字段）。
- 删除、新增等写操作**仅管理员可执行**，网格员会收到权限提示。

### 5. 数据录入（模板 / 批量导入）

面向「从 Excel 整理好的台账一次性导入」的场景。五个页签：**农户、服务网点、摄像头、通知公告、事件记录**。

| 操作 | 说明 |
| --- | --- |
| 切换页签 | 右侧自动展示该类数据的字段说明（字段名、必填、类型、取值范围、示例） |
| 「下载 CSV 模板」 | 下载带 BOM 的 UTF-8 模板，含表头 + 2 行示例，可直接用 Excel 打开 |
| 「复制表头」 | 只复制表头，方便粘贴到已有表格上对齐列 |
| 单条录入 | 页签下方表单逐项填写，提交前前端先校验，错误字段高亮并给出提示 |
| 批量粘贴 | 从 Excel 直接复制粘贴到文本框，自动识别 Tab / 逗号 / 分号 / 竖线分隔 |
| 「校验」 | 只校验不入库，逐行给出通过 / 错误 / 警告；错误行可展开看具体原因 |
| 「确认导入」 | 校验通过后入库；唯一键重复会提示「库中已存在」并跳过该行 |

校验规则举例：必填项缺失 → 错误；经纬度超出村域范围 → 警告；房屋状态不在枚举内 → 错误；户号重复 → 错误。网格员执行导入会被拒绝（仅管理员可写）。

演示建议：切到「农户」页签 → 下载模板 → 把示例行粘贴进文本框 → 点「校验」看统计条 → 点「确认导入」→ 回到「村户一张图」搜索新户号验证落图。

### 6. 系统接入

把「以后要换成什么」提前摆到台面上，方便现场讲对接方案。

**上半部分 · 地图服务接入**

## 七、常见问题

**Q1：地图是灰的 / 瓦片加载不出来？**
需要联网访问公开地图服务。若处于内网，请编辑 `data/map-providers.json`，把瓦片地址替换为内网地图服务地址（或提前代理缓存瓦片），重启服务即可，无需改前端代码。

**Q2：为什么矢量底图和影像底图上点位都能对齐？**
点位数据采用 WGS84 坐标；切到高德矢量底图时，前端会按标准算法把坐标转换为 GCJ02 再绘制（`mapkit.js` 中 `wgs2gcj`），因此不会出现几百米偏移。

**Q3：数据被改乱了怎么恢复？**
重跑 `npm run gen:data` 会重新生成 `data/*.json`；收藏/反馈/审计日志可调用 `POST /api/admin/reset` 清空（或直接删除 `data/runtime/` 下的文件后重启）。

**Q4：端口被占用？**
用环境变量指定端口，例如 `PORT=8080 npm start`（Windows：`$env:PORT=8080; npm start`）。

**Q5：这个原型能直接上线吗？**
不能。当前是演示原型：鉴权为前端角色模拟、问答为关键词检索、地图依赖公开瓦片、数据存于 JSON 文件。上线需接入统一身份认证、真实政策库/大模型、空间数据库与正式地图服务。

**Q6：怎么新增一套底图（比如政务内网地图 / 天地图）？**
编辑 `data/map-providers.json`，增加一项：`id`、`name`、`group`（satellite/vector）、`crs`（wgs84/gcj02）、`enabled`、`needKey`、`layers[]`（`{ url, maxZoom, attribution }`）。需要密钥的服务在 `url` 里写 `${TIANDITU_KEY}` 这类占位符，服务端 `/api/map/config` 会读环境变量解析后下发；网页端「系统接入」页会显示该服务状态，可用后自动出现在底图下拉框中。天地图只需 `set TIANDITU_KEY=xxx` 再重启即可启用。

**Q7：摄像头接的是真设备吗？怎么换成真实的？**
当前是接口层抽象 + 占位抓图：设备数据存在 `data/cameras.json`（含 `protocol`、`streamUrl`、`snapUrl`、`ptz`、`aiTags`），服务端按协议返回取流地址，抓图由服务端生成 SVG 占位图。接真设备时：GB/T 28181 设备填 `protocol: "gb28181"` 并补 `deviceId`/`channel`，由信令网关转流；RTSP/HLS/RTMP 设备直接填 `streamUrl`；前端播放换成 flv.js / hls.js 即可，不需要改业务代码。云台指令走 `POST /api/cameras/:id/ptz`，目前是演示级实现，真实环境需对接设备 SDK。

**Q8：批量导入支持哪些格式？**
页面上是「从 Excel 复制后粘贴」，自动识别 Tab、逗号、分号、竖线四种分隔；也支持「下载 CSV 模板」离线填好再整段粘贴。字段定义与校验规则统一由 `server/schemas.js` 维护，新增一类可导入的数据只需在该文件加一份 schema，模板下载、字段说明、逐行校验、单条表单会自动生成。

**Q9：导入错了怎么办？**
导入前先点「校验」（`mode=validate`）只看结果不入库；正式导入（`mode=commit`）会按唯一键去重，重复行提示「库中已存在」并跳过。若要整体还原，重跑 `npm run gen:data`。
