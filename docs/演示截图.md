## 一、网页端 · 地图信息展示平台

### 1. 综合态势

统计指标、村域地图（卫星影像）、实时预警与三张趋势图。

![村户一张图](screenshots/web-02-households.png)

![农户详情](screenshots/web-03-household-detail.png)

![完整台账](screenshots/web-04-full-profile.png)

答案按“适用对象 / 所需材料 / 办理流程 / 办理地点 / 政策依据”组织，右侧同步展示相关文件，支持转人工。

![政策问答](screenshots/web-06-qa.png)

### 7. 基础数据管理

农户台账、服务网点、通知公告、事件记录四个页签，写操作仅管理员可用。

![数据管理](screenshots/web-07-admin.png)

### 8. 数据录入（模板 / 批量导入）

五类数据页签、字段说明表、CSV 模板下载、Excel 粘贴批量导入；先校验（通过 / 错误 / 警告逐行反馈）再入库。

![数据录入](screenshots/web-09-import.png)

### 9. 系统接入（地图服务 / 视频监控）

上半部分为可插拔的底图服务配置与 Key 状态，下半部分为视频监控接入能力、在线率统计与设备清单，底部列出全部接口。

![系统接入](screenshots/web-10-integration.png)

### 10. 视频监控面板

点击地图上的摄像头打开：实时抓图、AI 标签、云台控制、抓拍与录像（抓图为服务端生成的占位图）。

![视频监控面板](screenshots/web-11-camera-panel.png)

### 11. 摄像头设备台账编辑

「系统接入」页设备卡右上角可编辑 / 删除，标题栏可新增。表单按字段元数据自动生成，采用两列宽版弹窗；编辑为局部更新，取流地址留空则表示沿用原地址。

![设备编辑](screenshots/web-12-camera-form.png)

## 三、图表与地图说明

- 趋势图使用原生 SVG 绘制，无第三方图表库依赖，断网也可正常显示。
- 地图使用 Leaflet + 在线瓦片，底图服务由 `data/map-providers.json` 声明式配置：卫星影像（Esri，WGS84）、矢量地图（高德，GCJ02）、天地图（需 Key）、自建瓦片。
  切换矢量底图时，前端按标准算法做 WGS84→GCJ02 纠偏，点位与道路、房屋仍保持对齐。
- 摄像头抓拍图为服务端即时生成的 SVG 占位图，不含任何真实画面；真实设备接入后替换为实际视频流即可。
- 农户点位由 `tools/extract-footprints.py` 从卫星影像中识别房屋位置后换算经纬度，再叠加随机微偏移生成，不对应任何真实住户。
