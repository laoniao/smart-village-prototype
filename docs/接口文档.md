# 接口文档（演示版）

- Base URL：`http://localhost:5178`
- 统一响应结构：

```json
{ "code": 0, "message": "ok", "data": {} }
```

`code` 为 `0` 表示成功；`400` 参数错误；`403` 无权限；`404` 资源不存在。

- 角色：请求头 `x-role: admin | grid`（默认 `grid`）。前端右上角切换角色即切换该请求头。
- 用户：请求头 `x-user`（默认 `demo-user`），用于收藏归属。

## 2. 农户

### GET /api/households

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| keyword | string | 户号 / 户主 / 地址 / 组别 模糊匹配 |
| group | string | 精确匹配组别，如 `一组` |
| status | string | `正常` / `待核查` / `闲置` |
| care | `1` | 仅重点关怀户 |
| page / size | number | 分页，`size` 最大 1000 |

返回 `{ total, page, size, rows: [] }`，手机号已脱敏（`138****2468`）。

### GET /api/households/stats

返回总数、按组别/状态分布、重点关怀数、家庭人口合计。

### GET /api/households/:id

单户脱敏详情。`:id` 支持 `A-023` 形式。

### GET /api/households/:id/full

完整台账（身份证、完整电话、成员列表）。

- 需要 `x-role: admin`，否则 `code=403`；
- 每次访问写入 `data/runtime/access-log.json` 审计日志。

### PATCH /api/households/:id

仅管理员。可维护字段：`houseStatus`、`members`、`care`（避免改动敏感字段）。

### POST /api/qa/ask

请求：

```json
{ "question": "农机购置补贴怎么申请？" }
```

响应（命中）：

```json
{
  "matched": true,
  "confidence": 0.89,
  "answer": {
    "policyId": "P-01",
    "title": "农机购置补贴申请指南",
    "summary": "支持农业生产的个人和农业生产经营组织购置补贴目录内的农机具。",
    "applyTo": ["从事农业生产的个人", "农业生产经营组织"],
    "materials": ["身份证明", "购机发票", "机具合格证"],
    "steps": ["选择机具并购买", "提交申请", "部门审核"],
    "place": "镇农业农村办公室（村便民服务站可代办）",
    "placePending": true,
    "basis": ["《农机购置补贴政策实施意见》"],
    "updatedAt": "2024-03-01"
  },
  "suggestions": ["需要准备哪些材料？"],
  "docs": [{ "id": "D-01", "title": "农机购置补贴政策实施意见", "dept": "农业农村部", "type": "官方文件" }]
```

## 8. 地图服务接入

### GET /api/map/config

返回可用的底图服务清单与当前生效项。服务端读取 `data/map-providers.json`，并把 `${ENV}` 占位符替换为环境变量值。

```json
{
  "defaultGroup": "satellite",
  "current": "esri-img",
  "providers": [
    {
      "id": "esri-img", "name": "Esri 卫星影像", "short": "影像",
      "group": "satellite", "crs": "wgs84",
      "url": "https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}",
      "annoUrl": "", "options": { "maxZoom": 18, "maxNativeZoom": 18, "attribution": "影像底图 © Esri" },
      "needKey": false, "enabled": true, "available": true, "keyConfigured": true,
      "desc": "ArcGIS Online 公开影像瓦片，开发演示可直接使用"
    },
    {
      "id": "tianditu-img", "name": "天地图影像", "group": "satellite", "crs": "wgs84",
      "needKey": true, "enabled": true, "available": false, "keyConfigured": false
    }
  ],
  "crs": { "logical": "wgs84", "note": "业务点位统一按 WGS84 存储；底图为 GCJ02 时前端自动纠偏。" },
  "env": { "TIANDITU_KEY": "天地图服务令牌", "MAP_PROVIDER": "指定默认生效的底图 id" }
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `group` | `satellite` / `vector`，前端按组显示“影像 / 矢量”按钮 |
| `crs` | `wgs84` 或 `gcj02`；为 `gcj02` 时前端对业务点位做 WGS84→GCJ02 纠偏 |
| `needKey` | 是否需要密钥；占位符 `${TIANDITU_KEY}` 未配置时 `available=false` |
| `enabled` | 配置中是否启用（自建瓦片默认关闭） |
| `available` | 综合判断结果：`enabled && keyOk` |

**新增一种底图**：在 `data/map-providers.json` 的 `providers` 数组里追加一项即可，前端无需改代码；设置环境变量 `MAP_PROVIDER=<id>` 可指定默认底图。

## 9. 视频监控接入

### GET /api/cameras/capabilities

设备接入能力清单，前端“系统接入”页据此渲染。

```json
{
  "protocols": [
    { "id": "gb28181", "name": "GB/T 28181", "desc": "公安/政务视频联网标准，支持 SIP 注册、目录订阅、云台控制", "stream": "sip", "ptz": true },
    { "id": "rtsp", "name": "RTSP / ONVIF", "stream": "rtsp", "ptz": true },
    { "id": "hls", "name": "HLS", "stream": "http", "ptz": false },
    { "id": "rtmp", "name": "RTMP / HTTP-FLV", "stream": "http", "ptz": true },
    { "id": "webrtc", "name": "WebRTC", "stream": "webrtc", "ptz": true }
  ],
  "features": ["实时预览", "云台控制", "抓拍", "录像与回放", "AI 事件推送", "设备心跳巡检"],
  "aiAlgorithms": ["人员聚集", "车辆识别", "烟火检测", "越界检测", "跌倒检测", "水位识别"]
}
```

### 设备相关接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /api/cameras?status=&protocol= | 设备列表（已隐藏真实取流地址） |
| GET | /api/cameras/stats | 总数 / 在线率 / 协议分布 / 厂商分布 / 云台与 AI 数量 |
| GET | /api/cameras/:id | 设备详情；`streamUrlFull` 仅管理员可见，网格员返回 `(管理员可见)` |
| GET | /api/cameras/:id/snapshot | 抓图，返回 SVG 占位图（含 LIVE/离线角标与时间戳） |
| POST | /api/cameras/:id/snapshot | 触发抓拍，返回 `{ id, at, url }`；离线设备返回 `code=503` |
| GET | /api/cameras/:id/stream | 取流地址（演示返回占位说明） |
| POST | /api/cameras/:id/ptz | 云台控制，`{ action, speed }`，action ∈ `up/down/left/right/zoomIn/zoomOut/reset/stop`；管理员权限 |
| POST | /api/cameras/:id/record | 录像控制，`{ action: "start" \| "stop" }` |
| POST | /api/cameras/heartbeat | 设备心跳上报，`{ id, status }` |
| POST / PUT / DELETE | /api/cameras/device[/:id] | 设备增改删（管理员） |

**接入真实视频的做法**：把 `data/cameras.json` 中对应设备的 `streamUrl` 换成平台取流地址（GB28181 由流媒体网关转 HLS/WebRTC），并实现 `/api/cameras/:id/stream` 返回播放地址；前端 `cam-shot` 容器换成 `<video>` 即可，云台与抓拍接口保持不变。

## 10. 录入模板与批量导入

### GET /api/schema

可录入的数据类型：`households`（农户台账）、`points`（服务网点）、`cameras`（视频监控设备）、`notices`（通知公告）、`events`（事件记录）。

### GET /api/schema/:entity

返回字段元数据，前端据此渲染字段说明与单条录入表单：

```json
{
  "entity": "households", "label": "农户台账", "uniqueKey": "houseNo",
  "desc": "一户一行。户号须唯一；经纬度用于地图落点。",
  "fields": [
    { "key": "houseNo", "label": "户号", "type": "text", "required": true, "desc": "格式建议：组别字母-序号", "sample": "A-429" },
    { "key": "group", "label": "所属组别", "type": "select", "options": ["一组", "二组"], "required": true },
    { "key": "members", "label": "家庭成员数", "type": "number", "min": 1, "max": 20, "unit": "人" },
    { "key": "lat", "label": "纬度", "type": "number", "min": 3, "max": 54 }
  ]
}
```

### GET /api/template/csv/:entity

下载 CSV 模板：UTF-8 BOM + 中文表头 + 两行示例（Excel 直接打开不乱码）。`Content-Disposition` 同时给出 `filename` 与 `filename*=UTF-8''...`，兼容中文文件名。

### GET /api/template/:entity

返回 `{ entity, label, csv, fields }`，供页面“复制表头 / 填入示例”使用。

### POST /api/import/:entity?mode=validate|commit

批量导入，管理员权限。请求体：

```json
{ "text": "户号\t户主姓名\t所属组别\t门牌地址\t家庭成员数\t房屋状态\nB-901\t王某\t一组\t示范村一组901号\t3\t正常",
  "mode": "validate" }
```

- `text`：分隔文本，自动识别 `Tab / 逗号 / 分号 / |`；首行为表头，按中文名或字段名映射，支持带引号的 CSV。
- 也可传 `rows: [{...}]` 直接给对象数组。
- `mode=validate` 只校验不写库；`mode=commit` 仅写入通过校验的行。

响应：

```json
{
  "entity": "households", "total": 2, "valid": 1, "invalid": 1, "mode": "validate", "imported": 0,
  "results": [
    { "index": 1, "line": 2, "ok": true, "errors": [], "warnings": [], "value": { "houseNo": "B-901" } },
    { "index": 2, "line": 3, "ok": false,
      "errors": [{ "key": "houseNo", "label": "户号", "msg": "库中已存在「A-001」，请勿重复导入" }],
      "warnings": [{ "key": "lat", "label": "纬度", "msg": "坐标不在示范村范围内，请确认" }] }
  ]
}
```

校验规则：必填、数值范围、日期格式（`YYYY-MM-DD` / 日期时间）、下拉选项、正则（仅提示）、坐标是否在村域范围内（仅提示）、本次导入内唯一键重复、与库内已有记录重复。

## 12. 后续对接建议

| 原型实现 | 正式环境建议 |
| --- | --- |
| `x-role` 请求头模拟角色 | 统一身份认证（OAuth2 / 政务微信），服务端会话与 RBAC |

| 摄像头占位抓图 | 视频平台（GB28181 联网）+ 流媒体网关转 HLS/WebRTC |
